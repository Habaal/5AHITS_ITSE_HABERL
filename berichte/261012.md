## Übung 1: PHP-Grundlagen und Cheat Sheet

**Aufgabenstellung:** PHP-Grundlagen wiederholen, zum Beispiel mit w3schools. Als Arbeitsbericht kommt ein Cheat Sheet der wichtigsten PHP-Befehle und Konstrukte dazu.

### Erster Test

```php
<?php
$name = "Martin";
echo "Hallo " . $name . "!";
```

Im Terminal ausgeführt mit `php hallo.php`. Das ist die Variante ohne Webserver, PHP läuft hier direkt auf der Kommandozeile.

### Cheat Sheet

Quellen: [1] w3schools PHP Tutorial, [2] PHP-Handbuch (siehe Quellenverzeichnis).

**Grundlagen**

| Thema | Beispiel | Quelle |
|---|---|---|
| PHP-Block | `<?php ... ?>` | [1] |
| Kurzes Echo | `<?= $x ?>` | [1] |
| Ausgabe | `echo "Text";` | [1] |
| Kommentare | `// einzeilig`, `# einzeilig`, `/* mehrzeilig */` | [1] |
| Variablen | `$name = "Max";` (beginnen immer mit `$`) | [1] |
| Konstanten | `define("PI", 3.14);` oder `const PI = 3.14;` | [1] |
| Datentypen | string, int, float, bool, array, null | [1] |
| Typ prüfen | `var_dump($x);`, `gettype($x)` | [1] |
| Verketten | `"Hallo " . $name` (der Punkt verbindet Strings) | [1] |

**Operatoren**

| Art | Operatoren |
|---|---|
| Arithmetisch | `+ - * / % **` |
| Zuweisung | `= += -= .=` |
| Vergleich | `== === != !== < > <= >=` |
| Logisch | `&& \|\| !` |
| Inkrement | `$i++`, `$i--` |
| Null-Coalescing | `$x = $_POST["a"] ?? "standard";` |

Merke: `===` vergleicht Wert und Typ, `==` nur den Wert.

**Kontrollstrukturen**

```php
if ($a > 5) { ... } elseif ($a == 5) { ... } else { ... }
switch ($tag) { case "Mo": ...; break; default: ...; }
for ($i = 0; $i < 10; $i++) { ... }
while ($i < 10) { ... }
foreach ($array as $key => $wert) { ... }
```

**Arrays**

| Befehl | Bedeutung |
|---|---|
| `$a = [1, 2, 3];` | Array anlegen |
| `$a[] = 4;` | Element anhängen |
| `$a["key"] = "wert";` | assoziatives Array |
| `count($a)` | Anzahl der Elemente |
| `array_sum($a)` | Summe |
| `min($a)`, `max($a)` | kleinster und größter Wert |
| `array_filter($a, fn)` | Elemente filtern |
| `sort($a)`, `rsort($a)` | sortieren |
| `in_array($x, $a)` | ist das Element enthalten? |
| `implode(", ", $a)` / `explode(",", $s)` | Array zu String und zurück |

**Funktionen und Strings**

```php
function addiere(int $a, int $b = 0): int {
    return $a + $b;
}
```

| Befehl | Bedeutung |
|---|---|
| `strlen($s)` | Länge |
| `strtoupper($s)`, `strtolower($s)` | Groß- und Kleinschreibung |
| `str_replace("a", "b", $s)` | ersetzen |
| `substr($s, 0, 3)` | Teilstring |
| `round($x, 2)` | runden |
| `random_int(1, 100)` | Zufallszahl, kryptografisch sicher (besser als `rand()`) |
| `isset($x)`, `empty($x)` | gesetzt oder leer? |
| `is_numeric($x)` | ist es eine Zahl? |

**Formulare und Superglobals**

| Konstrukt | Bedeutung |
|---|---|
| `$_GET["name"]` | Daten aus der URL |
| `$_POST["name"]` | Daten aus einem POST-Formular |
| `$_SERVER["REQUEST_METHOD"]` | Request-Art prüfen, zum Beispiel `"POST"` |
| `$_SESSION["x"]` | Daten über mehrere Requests speichern, braucht `session_start();` |
| `htmlspecialchars($s)` | Schutz vor XSS bei der Ausgabe |

**Sonstiges:** `include "datei.php";` / `require`, `date("d.m.Y")`, `header("Location: x.php");`

### 2.1 Notenverwaltung (`php/noten.php`)

**Aufgabenstellung:**

* Mehrere Noten über ein Formular eingeben
* Noten in einem Array speichern
* Durchschnitt, beste und schlechteste Note sowie die Anzahl der positiven Noten berechnen
* Ausgabe als HTML-Tabelle

**Idee:** Das Formular hat fünf Eingabefelder mit `name="noten[]"`. Dadurch kommen die Noten als Array per POST an. Es werden nur Werte von 1 bis 5 übernommen, leere und ungültige Eingaben fallen weg. Eine Note gilt als positiv, wenn sie 4 oder besser ist.

**Kern der Auswertung:**

```php
$durchschnitt = array_sum($noten) / count($noten);
$beste        = min($noten);
$schlechteste = max($noten);
$positive     = count(array_filter($noten, fn($n) => $n <= 4));
```

**Test 1:** Noten 2, 3, 5, 1, 4

```
Eingegebene Noten   2, 3, 5, 1, 4
Durchschnitt        3
Beste Note          1
Schlechteste Note   5
Positive Noten      4 von 5
```

**Test 2:** Noten 5, 5, `x`, 7. Das `x` und die 7 werden ignoriert, übrig bleiben 5 und 5.

```
Eingegebene Noten   5, 5
Durchschnitt        5
Positive Noten      0 von 2
```

Das stimmt mit der Rechnung überein.

### 2.2 Passwort-Generator (`php/passwort.php`)

**Aufgabenstellung:**

* Länge über ein Formular festlegen
* Zufälliges Passwort erzeugen
* Optionen: Groß- und Kleinbuchstaben, Zahlen, Sonderzeichen

**Idee:** Je nach angekreuzter Checkbox wird ein Zeichenvorrat zusammengebaut. Daraus wird Zeichen für Zeichen mit `random_int` gezogen. Die Länge wird auf 4 bis 64 begrenzt. Ohne gewählte Option erscheint eine Fehlermeldung.

**Kern:**

```php
for ($i = 0; $i < $laenge; $i++) {
    $passwort .= $zeichen[random_int(0, strlen($zeichen) - 1)];
}
```

**Tests:**

| Eingabe | Ergebnis |
|---|---|
| Länge 20, alle Optionen | `r_M7HMUPNlR5jpV#7mgC` (20 Zeichen) |
| Länge 8, nur Zahlen | `55973950` |
| Länge 8, keine Option | „Bitte mindestens eine Option auswählen.“ |

### 2.3 Zahlenratespiel (`php/raten.php`)

**Aufgabenstellung:**

* Der Server erzeugt eine Zufallszahl
* Der Benutzer gibt einen Tipp ab
* PHP antwortet mit „zu hoch“, „zu niedrig“ oder „richtig“
* Die Anzahl der Versuche wird mitgezählt

**Idee:** HTTP merkt sich nichts zwischen zwei Requests. Würde die Zufallszahl einfach bei jedem Aufruf neu gewürfelt, wäre sie nach jedem Tipp eine andere. Deshalb liegen die Zahl und der Versuchszähler in der Session (`session_start()`, `$_SESSION`). Der Button „Neues Spiel“ würfelt neu.

**Test:** Ich habe das Spiel mit Binärsuche gespielt (immer die Mitte raten), dabei wurde das Cookie der Session mitgeschickt:

```
Tipp 50 -> Zu niedrig!
Tipp 75 -> Zu niedrig!
Tipp 88 -> Zu hoch!
Tipp 81 -> Zu niedrig!
Tipp 84 -> Zu niedrig!
Tipp 86 -> Zu niedrig!
Tipp 87 -> Richtig! Gelöst in 7 Versuch(en).
```

Die Zahl blieb über die Requests gleich, der Zähler zählte richtig mit (7 Tipps, 7 Versuche).
